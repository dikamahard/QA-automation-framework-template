# Base Automation Template (Web and Mobile)
Use this repo to initiate new automation project

## Modify according to your project
1. Jenknkinsfile (Web or Mobile)
    - project related data
    - email
    - tag name
    - email subject
    - test name on stage test
    - file name for excel
2. pom.xml
    - artifact id
3.  testcase/template
4. helper/ExcelUtils
    - file path excel
5. testNGSuites/testng.xml
   - define test to run on pipeline stage test
